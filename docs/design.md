# IP Atlas design

An Explore / Inspect tool: the map is the workspace; the left rail is the query and evidence.

Reference: Apple Maps' stable sidebar beside a large map, and Primer's keyboard focus and readable data hierarchy. Borrow the spatial model, not their visual identity.

Palette: porcelain #f8faf8; ink #203c39; forest #176657; water #e5eeeb; land #fbfcf8; boundary #b7cac3. Dark mode uses moss #142b29, pale ink #e7f0eb and mint #95c9b7. No gradients or glass.

Type: Manrope for interface and wordmark; IBM Plex Mono only for IP addresses and coordinate values; Chinese uses PingFang SC. Type scale 12 / 14 / 16 / 22 / 32. Layout 8px spacing, 6 / 12 / 20px radii.

Desktop: 68px masthead; 372px fixed-width query rail; remaining width is a quiet atlas. Mobile: form and result first, 360px interactive map next, recent lookups last.

Review: a large hero and feature-card grid would obscure the task. Use a real geographic canvas, concise field rows and a single forest accent. The defining detail is a cartographic crosshair marker and direct place label, not decorative statistics. No street zoom, precise-location claims, fake live activity or animated radar.
